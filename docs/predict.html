What counts as one number? What if my code fetches other data?

Return a plain number: return 31.4, or return float(x) when x comes out of pandas. A list, a table or None fails the test.


The tests run in your browser. Some websites refuse requests from a web page, so code that downloads other data may fail here even though it works in Colab. If that happens, the error says so, and you can still submit: at the close your code runs on a normal computer, where downloads work.
